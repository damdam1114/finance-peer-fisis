# 캐피탈사(여전업권) 데이터셋 정의

표 양식은 `../../shared/table_format.md`, API 메타는 `../../shared/fisis_api_spec.md` 참조.

## 1. 권역 구조 — 여전업권은 4개로 쪼개져 있음

FISIS는 여신전문금융업을 단일 권역으로 두지 않는다.

| 권역 | 코드 | 비고 |
|---|---|---|
| 리스사 | K | **KB캐피탈 소속 (확정)** |
| 할부금융사 | T | 비교대상 4개사 소속 (현대·하나·우리금융·메리츠) |
| 신기술금융사 | N | - |
| 신용카드사 | C | 별도 권역 |

**확정 (2026-07, catalog 전수 수집 결과)**:
KB캐피탈 = `케이비캐피탈㈜`, **권역 K(리스사), financeCd `0010250`**.
이전 시도의 `partDiv=A(국내은행) + financeCd=0010250 → 000/0건`은 에러가 아니라
"KB캐피탈이 A권역에 없음"이란 뜻이었음. **0010250은 KB캐피탈이 맞고, 등록 권역은 A가 아니라 K.**

**중요 — 비교대상이 K·T 두 권역에 걸쳐 있음**:
- K(리스사): KB캐피탈, 신한캐피탈
- T(할부금융사): 현대·하나·우리금융·메리츠캐피탈

다만 여전 4개 권역(K/T/N/C)의 **주요경영지표(smlDiv=C) 통계표는 권역별로 동일 구조**다.
list_no는 `S{권역}{번호}` 형식이라 권역만 다르고 번호·계정(account_cd)은 동일하다.
예: 수익성은 리스사 `SK009`, 할부금융사 `ST009` — 두 표의 account_cd/account_nm이 완전히 일치(확인함).
→ **권역이 갈려도 각 회사를 자기 권역의 같은 번호 통계표로 조회하면 동일 지표를 얻을 수 있어 비교 가능.**
  (신용카드사 C의 연체채권비율표 SC117만 계정이 약간 다르나, 비교대상엔 카드사가 없어 무관.)
카탈로그 원본: `capital/schema/fisis_catalog.json`(+ 사람용 요약 `fisis_catalog.md`).

## 3. 통계표 분류 (smlDiv) — 프리뷰 매핑

| 분류 | smlDiv | 프리뷰 활용 |
|---|---|---|
| 일반현황 | A | 회사 기본정보(우선순위 낮음) |
| 재무현황 | B | 자산·부채·손익 규모 → 수익성 분모 |
| 주요경영지표 | C | **ROA·ROE·연체율·NPL 등 핵심** |
| 주요영업활동 | D | 취급액·상품별 실적 |
| 보도자료통계 | P | 참고 |

우선순위: **C(주요경영지표) → B(재무현황) → D(주요영업활동)**

### 3-1. 프리뷰 지표 → list_no / account_cd 매핑 (확정, 2026-07)

실제 `list_nm`/`account_nm` 기준으로 확정. list_no는 권역 접두어만 다름
(리스사=SK___, 할부금융사=ST___). 아래 번호·account_cd는 K·T 공통.
account_cd 옆 `[원]`=원 단위 금액, `[%]`=이미 산출된 비율.

**수익성 — 통계표 `S{권역}009` "수익성" (계정 10개)**

| 프리뷰 지표 | account_cd | account_nm | 단위 | 비고 |
|---|---|---|---|---|
| ROA | `F` | 총자산순이익률(ROA) | % | 공시비율 |
| ROE | `J` | 자기자본순이익률(ROE) | % | 공시비율 |
| NIM | **없음** | — | — | **여전 카탈로그에 산출 비율 없음** |
| 총영업이익률 | **없음** | — | — | 영업이익(금액)만 존재(SK118/E 등), 비율 미제공 |
| (분모/보조) | `A` 총자산(평잔)[원], `I` 자본(평잔)[원], `E` 당기순이익[원], `B` 세전수익[원], `C` 세전비용[원], `D` 총경비[원], `G` 총자산경비율[%], `H` 수지비율[%] |||

> NIM·총영업이익률은 FISIS 여전 통계에 **없음**. 필요하면 SK118/ST118(요약손익계산서)의
> 금액 항목으로 자체 산출해야 하며, 그 경우 산식을 각주에 명기하고 "공시치 아님"을 표시할 것.
> 수치를 임의로 만들지 말 것 — 산출 근거가 없으면 "없음"으로 남긴다.

**건전성 — 통계표 `S{권역}008` "여신건전성" (계정 11개)**

| 프리뷰 지표 | account_cd | account_nm | 단위 |
|---|---|---|---|
| 고정이하여신비율 | `D` | 고정이하여신비율 | % |
| 대손충당금적립률 (요적립액 대비) | `E` | 대손충당금적립비율(요적립액 대비) | % |
| 대손충당금적립률 (총여신 대비) | `F` | 대손충당금적립비율(총여신 대비) | % |
| 대손충당금적립률 (고정이하여신 대비) | `G` | 대손충당금적립비율(고정이하여신 대비) | % |
| (분자/분모) | `A` 총채권[원], `A1~A3` 고정/회수의문/추정손실[원], `A4` 고정이하여신[원], `B` 요적립액[원], `C` 실적립액[원] |||

> **대손충당금적립률은 3종(E/F/G)** — 분모가 다르다. 어느 것을 쓸지는 프리뷰 표준 정의에 맞춰
> 택하고 각주에 분모를 명기할 것. 내부 CCR(충당금전입액÷평잔)과는 분자·분모가 달라 직접 비교 불가.

**연체율 — 통계표 `S{권역}117` "여신건전성(연체채권비율)" (계정 7개, 카드사 C만 8개)**

| 프리뷰 지표 | account_cd | account_nm | 단위 |
|---|---|---|---|
| 연체율 | `B` | 연체채권비율 | % |
| (분자/분모) | `A` 총채권(대차대조표 기준)[원], `A1~A4` 연체구간별 연체액[원], `A5` 연체액계[원] |||

> 참고 통계표: `S{권역}007` 자본적정성(조정자기자본비율 등), `S{권역}010` 유동성.

## 4. 기간 대응의 구조적 한계 (중요)

FISIS는 `term`이 **Y/H/Q만 지원하고 월 단위 조회가 불가능**하다.
프로젝트 표준 시계열과 대조:

| 표준 시계열 | FISIS 대응 | 가능여부 |
|---|---|---|
| FY23 | term=Y, 202312 | 가능 |
| FY24 | term=Y, 202412 | 가능 |
| FY25 | term=Y, 202512 | 가능 |
| 25.6월 | term=Q, 202506 (2Q말) | 가능 |
| 26년 최신월(26.4·26.5월) | — | **불가** |
| 26.1H(202606) | term=Q/H, 202606 | **현재 미공시(공시 시차 확인됨)** |

→ **경쟁사 비교 표는 분기말 기준으로만 작성 가능.** 내부 자료의 26.4·26.5월 값과 직접 병치하면
기준이 어긋나므로, 비교표는 별도로 두고 각주에 기준 차이를 명기할 것.

→ 또한 검색기간은 **최대 40분기** 제한(err_cd 103). FY23~26.1H는 약 14분기라 문제없음.

→ **공시 시차 실측(2026-07-24 조회)**: KB캐피탈 SK009를 202303~202606으로 조회했으나
실제 반환된 마지막 분기는 **202603(26.1Q)** 이고 **202606(26.2Q)은 아직 미공시**.
여전 분기통계는 약 1개 분기 지연되어 올라오므로, 26.2Q 비교치는 다음 수집 때 재확인할 것.
(err_cd는 000 정상 — 요청 기간을 넘겨도 있는 분기까지만 돌려준다.)

## 5. 내부 지표와의 산식 충돌 주의

- FISIS NIM은 **보유자산 기준**(이자이익 ÷ 운용자산 평잔). KB캐피탈 원페이저의 "신규 NIM"
  (신규 내부수익률 − 신규 조달원가, 플로우 기준)과 **다른 개념** — 혼용 금지.
- FISIS 대손충당금적립률 산식이 내부 CCR(충당금전입액 ÷ 평잔)과 다를 수 있음.
  raw 응답의 `account_nm`·`unit`을 확인해 분자·분모를 특정한 뒤 각주 처리.
- FISIS는 이미 산출된 비율을 제공하는 경우가 많음 → 표준의 "비율 직접입력 금지" 원칙과 충돌.
  이 경우 **"공시비율(참고)" 열로 분리 표기**하고 자체 재계산 불가함을 각주에 명시.
  (ROA/ROE/고정이하여신비율/연체채권비율/대손충당금적립률 모두 FISIS가 % 로 직접 제공 → 공시치.)

### 단위 환산 (실측 확정, 2026-07)

주요경영지표 통계표(009/008/117)의 `description/unit`은 모두 **`"원,%"`** 로 반환된다.
이는 표 안에 **원 단위 금액 항목과 % 비율 항목이 섞여 있다**는 뜻이며, 하나의 계수로 일괄 환산하면 안 된다.

- **금액 항목은 원(KRW) 단위** — 실측: KB캐피탈 SK009 총자산(평잔)=17,485,628,000,000 = 17.49조.
  → **십억원 환산 = ÷ 1,000,000,000 (÷10^9)**. (스펙 초안의 "억원이면 ÷10"은 이 카탈로그엔 해당 없음.)
- **비율 항목(account_cd F/J/D/E/G/B 등)은 이미 % 값** — 환산 불필요, 그대로 사용.
- 어느 account_cd가 금액이고 어느 것이 비율인지는 §3-1 표의 `[원]`/`[%]` 표시를 따를 것.
  (raw JSON에는 항목별 단위 구분이 없으므로 이 매핑표가 유일한 근거.)
