## 반드시 읽을 각주 / 주의

1. **공시비율(참고)**: ROA/ROE/고정이하여신비율/연체채권비율/대손충당금적립률은 FISIS가
   산출해 제공한 비율을 **그대로** 옮긴 것. 표준의 "비율 직접입력 금지"에 따라 자체 재계산이
   아니라 공시치이며, 내부 산식(예: 신규 NIM, CCR)과 **개념이 다를 수 있으므로 혼용 금지**.
2. **NIM·총영업이익률**: FISIS 여전 통계에 산출 비율이 **없음**. 이 표에 포함하지 않음.
3. **당기순이익(십억원)**: FISIS 공시값은 **연환산(연간 기준)** 이라 분기 단독 손익이 아님.
   기준값이 0 이하인 분기는 Gap% 를 `N/A(기준≤0)` 로 표기(증감률 무의미).
4. **대손충당금적립률 = 총여신 대비(확정)**: SK/ST008 account `F`(대손충당금 실적립액 ÷ 총여신).
   FISIS가 제공하는 3종(요적립액 대비=E / 총여신 대비=F / 고정이하여신 대비=G) 중 프리뷰 표준
   정의에 따라 **총여신 대비(F)** 를 채택. E·G가 필요하면 raw(SK/ST008)에서 직접 조회 가능.
5. **26최신월 = 26.1Q(202603)**: 26.4·26.5월 등 비분기말은 FISIS 조회 불가. 내부자료의
   월값과 직접 병치 금지, 기준 차이 각주 필수. 202606은 공시되면 재수집.
6. **[확인 필요 — FISIS 원본 이상치] 하나캐피탈 25.6월(202506) 총자산 평잔 = 28,251.9십억**:
   전후 분기(약 18,000~19,000십억)와 크게 어긋남. **raw 원본 값 그대로**이며 임의 수정하지 않음.
   FISIS 원자료 오류 가능성이 있으니 사용 전 공시 원문 대조 요망. (연체율·비율 등 다른 지표는 정상 범위)
