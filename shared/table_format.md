# 공통 표 양식 규칙 (캐피탈 · 저축은행 공용)

원본: 프로젝트 「표양식_표준.md」. 이 리포의 모든 `processed/*.csv`는 아래 규칙을 따른다.

## 시계열 열 구성
| FY23 | FY24 | FY25 | 25.6월 | 26년 최신월 | Gap |
|---|---|---|---|---|---|
- 저량(잔액성) = 기말값 / 유량(손익·실행) = 기간누적
- 최신월 6월 미확정 시 26.4 또는 26.5 사용
- Gap = 25.6월 대비 26최신 비교
  - 금액 지표 → Gap금액 + Gap%(2열)
  - 비율 지표 → 차이값만(1열, %p)

## 단위·표기
- 기본 단위 십억원, 헤더에 `(단위: 십억원, %)` 명시
- % 기호 생략, 숫자만(30.5% → 30.5)
- 음수 △
- 연환산: 6개월 누적 ×2, 4개월 누적 ×3

## 비율 산출
- **비율 직접입력 금지** — 분자 블록 + 평잔 블록을 두고 비율은 그 블록을 참조하는 수식
- 평잔 = (전년말 + 당년말) ÷ 2
- FISIS가 이미 산출된 비율만 제공하는 항목은 "공시비율(참고)" 열로 별도 표기하고, 자체 재계산이 불가능함을 각주에 명시

## CSV 컬럼 헤더 예시
```
회사명,financeCd,항목,FY23,FY24,FY25,25.6월,26최신월,Gap금액,Gap%,비고
```
(비율 지표는 `Gap금액,Gap%` 대신 `Gap(%p)` 단일 컬럼)

## 행 순서
- 총계(소계) 상단 → 세부 들여쓰기 하단
- 회사 비교표는 KB(자사) 최상단 고정 → 이후 자산규모 내림차순
